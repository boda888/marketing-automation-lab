# Insights the owner can apply

Newest first. Each entry: one line of what to do, why, and the source. Only add entries that
change something concrete (a Clay column, an n8n node, a sequencer or CRM setting, a buying
decision). If a later run disproves an entry, strike it through and say why — do not delete.

Format: `- YYYY-MM-DD · <channel> · <action> — <why>. Source: <URL or note>`

- 2026-10-28 · calls · Make AI-call creation impossible to double-dial: Retell — stable `idempotency_key` per call task (deduped for 1 h; the SDK never retries creation); Vapi — no idempotency field and the SDK retries `calls.create` twice on 408 / 429 / 5xx, so set `maxRetries: 0` (or Retry On Fail off in n8n), mark a timeout as unknown and look the call up before redialling. Source: research/notes/2026-10-28-R6-voice-agents-dialer-api.md
- 2026-10-28 · calls · Switch the DNC defaults on: Retell `honor_internal_dnc: true` on every call and `enable_dnc_detection: true` on the agent (both default false), then copy `user_requested_dnc` into your global suppression list for email and LinkedIn too. In Vapi campaigns, use the `campaign.predial` webhook as the consent gate — anything but `{eligible: true}` skips the dial. Source: same note
- 2026-10-28 · calls · Route on the end reason, not on "call ended": no answer / busy / voicemail → callback task while the sequence keeps going; invalid destination or unallocated number → bad-phone fix, no retry; `marked_as_spam` → rest that caller number; `credit_exhausted` / `concurrency_limit_reached` → alert. Write to the CRM from Retell `call_analyzed` (summary, sentiment, custom fields), and for JustCall webhooks re-read the call by id first — its signature does not cover the body. Source: same note
- 2026-10-26 · linkedin · HeyReach API has no dedupe flag and makes you pick the sender per lead (`accountLeadPairs[].linkedInAccountId`): in n8n / Clay assign the sender yourself (owner or round-robin within a weekly budget per sender) and call `campaign/GetCampaignsForLead` by profile URL before `AddLeadsToCampaign`. Source: research/notes/2026-10-26-R5-linkedin-tools-api-limits.md
- 2026-10-26 · linkedin · HeyReach webhooks: use either `MESSAGE_REPLY_RECEIVED` or `EVERY_MESSAGE_REPLY_RECEIVED` per flow (both = the first reply processed twice) and always list `campaignIds` — empty means every campaign in the workspace. Source: same note
